## Getting Started

Start by opening `view_***_results.ipynb` to explore the existing results.

The `Results/` folder contains the experimental results along with the pulses used to produce them.

To reproduce the experimental results:

1. Calibrate your gate (`SX` or `X`) using `**_calibration_exp.ipynb`.
2. Run `QPT_**_exp.ipynb` and `RB_**_exp.ipynb`, importing the corresponding calibration `.json` files.
